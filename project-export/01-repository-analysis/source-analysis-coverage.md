## Method and limitations

Source files were fully decoded/indexed for declarations/imports/error/call markers; coherent module reviewers reconstructed data/control flow, implementation status and limitations using actual bodies and test contracts. Every production/helper file has an assignment. The symbol inventory has1,833 lexical candidates, not1,833 confirmedAPI methods. Compressed statements/lambdas and comments can produce lexical false positives; signatures are locators without implementation bodies. Parent separately checked source-file/line existence, cross-links, field coverage and high-risk implementation counterexamples.

No vendor binary decompilation, proprietary index decoding, formal static callgraph, full native Office validation, secret-value extraction or live service requests were used. Excluded secrets were hashed only for immutability, never content-exported. Source preservation is a separate before/after byte check; see [preservation](../14-audit/source-preservation.json).
