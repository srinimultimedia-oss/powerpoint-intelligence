## Design spike and limitations

- Proposed AD-006: .NET Framework 4.8 VSTO project, XML ribbon, WinForms status pane for this spike. React/WebView2 and command bus are deferred. The full project must be built with the Office workload before any loadability claim.
- Proposed AD-009: shape.CustomerData XML plus supplemental semantic GUID tag. Office documents that customer data travels with copied objects. Verify that behavior on approved Office builds. No shape ID serves as persistent identity; first valid occurrence in slide order keeps its ID, subsequent copies receive new IDs. Moving a copy before the original can change which instance retains the old ID.
- Deleted objects have no separate registry to prune. Unrelated XML namespaces are ignored. Missing, corrupt, conflicting, duplicate XML parts, unknown schema/type, and unsupported structural native edits remain intact and produce diagnostics. There is no automatic attempt to reconstruct missing canonical data from an arbitrary chart.
- Data is canonical in the XML; formatting stays in the native chart and is never redrawn by reopen/inspection. Before save or explicit inspection, compatible native chart edits are captured. S0 handles the rectangular finite numeric sample; advanced blank/error-cell semantics, native undo fidelity, grouping, large charts, arbitrary structural edits and transactional rollback under COM failure are not validated.
- Update rollback attempts to restore the previous data; rollback itself may fail if COM/document access is lost. Native undo and this failure path need manual evidence before a robustness claim.
- Integration harness opens visible Office only with an explicit flag, creates test presentations, and closes only its own documents. It never quits a user's PowerPoint process. Therefore close-document/reopen evidence from it would not prove a full process restart.
- Test signing/distribution is unresolved. No certificate or registry trust changes are committed. Q-001/Q-002/Q-007 require owner input (requested in chat); all other open decisions remain unresolved. Installed consumer Office is an observation, not a chosen supported estate.
