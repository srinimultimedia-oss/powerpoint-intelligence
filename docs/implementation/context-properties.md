## Behavior and implementation

The missing behavior was an automatic selection-driven inspector: existing element commands were available only through the ribbon and separate dialogs. `ThisAddIn` now creates one owned floating properties window, coalesces selection changes, and disposes it at shutdown. A 300 ms UI-thread timer checks selection identity; full property inspection is limited to 1.5-second intervals unless invalidated. The window requests show without activation, follows native screen coordinates, clamps to the PowerPoint window/monitor work area, and hides for invalid selection, deactivation and slide show. Closing it suppresses it until the selection changes; Intelligence > Properties reopens it.

Shared controls include font family, size, bold, italic, text color, horizontal/vertical alignment, text direction, solid fill and outline color. Controls use the supported intersection for multi-selection, show mixed/unknown values, and disable unsupported properties. Family actions dispatch to existing text-shape, process-grid, indicator, connector, chart, table, template, annotation and agenda editors. Ordinary shapes/groups and pictures receive only applicable native controls. Chart fonts apply chart-wide; individual series/axes use their dedicated editors. Indicators and managed connectors update canonical state rather than blindly recoloring their component groups.

The bridge validates presentation/window/slide/shape and text/table-cell identities again before mutation. Queued controls retain the identity they originally displayed. Common color pickers and template choices recheck after the dialog. Existing advanced editors retain their own target/ownership policies; this change does not certify every legacy editor against all modal selection changes. Font operations prevalidate targets and snapshot character-level properties for rollback. Bounded inspection allows 500 native parts, 16 group levels, 400 table cells and 2,000 selected text characters; oversized/unsupported groups receive a read-only explanation.

Production files: `ContextPanelModel.cs`, `ContextFormatting.cs`, `ContextChartFormatting.cs`, `ContextSelectionBridge.cs`, `ContextPropertiesView.cs`, `ContextPropertiesController.cs`, `ContextActionRouter.cs`. `NativeFormatting.SelectedShapes` now honors child-group selections. The automation API adds a read-only, text-free `GetContextPropertiesState` observation for native tests.

It accepts zero horizontal/vertical extents, including coincident attached sites; free-coordinate coincident endpoints remain rejected by the existing schema policy. Reads do not normalize or mutate the connector's rotation. Nonfinite, negative-size and excessive transforms are rejected, and existing slide-bound checks remain.

Rollback snapshots now include native bounds, rotation and flips; restoration reapplies and verifies them rather than silently flattening a rotated connector. Failure to verify restoration remains an explicit Use Undo error. Route, attachment, metadata and chart-point constraints are otherwise unchanged; arbitrary grouped/3D transforms are not claimed supported.
